# Novaro Solution — organic growth

No ranking, traffic, or backlink number is promised. This file records what the site does today and what to do next. It is not a claim about Google.

Canonical host: `https://www.novarosolution.com`. The app 301s `novarosolution.com` to www. HTTP to HTTPS is a host setting. Do not change DNS from the repo.

There is no Search Console export, keyword-volume tool, or backlink index in this project. GA4 is already set as `G-3Z1Z971K06`. A successful contact form sends `generate_lead` with `page_path` only. No name, email, or message is sent.

## What is indexable

Home, about, services, four service pages (`web-app-eng`, `ai-machine-ml`, `digital-marketing`, `cloud-devops`), work and four case studies, blog and posts, contact, `/software-development-usa`, `/it-services`, and four legal pages. `/admin` and `/api` are disallowed. The sitemap lists the public URLs.

One English site. `en` / `en-US` hreflang pairs were removed because both pointed at the same URL. Visible FAQs stay. `FAQPage` JSON-LD was removed because that rich result is limited to government and health sites.

## Authority

Earn links by publishing something a US founder can use.

- Keep the LinkedIn company page, the site, and `llms.txt` on the same facts: Gandhinagar studio, remote delivery, no US office.
- Profiles worth a real listing, filled out by a person: Clutch, GoodFirms, and the Google Business Profile for the Gandhinagar studio only.
- Offer one useful article to a newsletter or community you already read. Do not buy links, use private blog networks, or post the same comment on forums.

Once a month: export Search Console links if you have access, note new referring domains, and drop any directory that wants payment for a followed link.

## 30 / 60 / 90

**30 days.** Deploy only when you approve it. In Search Console, submit `https://www.novarosolution.com/sitemap.xml` for the www property. Confirm `G-3Z1Z971K06` is the GA4 property you can open. Send one test enquiry and confirm a single `generate_lead` event, then delete that test lead.

**60 days.** Read the US queries that actually appear. Publish the next article only if a query is not answered by a current URL. Candidates, in order: choosing a software partner for a US startup (only if `/software-development-usa` and `/blog/working-with-us-teams` do not already rank for it), a Next.js technical SEO checklist that goes past `/blog/tech-seo-tips`, what to decide before a mobile app, how to cut cloud cost after launch.
