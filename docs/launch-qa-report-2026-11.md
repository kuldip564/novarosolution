## 2. Issues fixed (this pass)

- **#3 Layout shift:** removed `content-visibility: auto` from page sections. Homepage CLS is now **0.000** at every width tested (was up to 0.377).
- **#4 Service panel contrast:** removed the scroll-linked fade; the slide-up movement stays. Lighthouse accessibility is now 100.
- **#5 Form fallback:** every 5xx failure now ends with "Please try again in a minute, or email novaro@novarosolution.com or call +91 96244 98325."
- **#6 Source note contrast:** opacity removed. Lighthouse accessibility is now 100.
- **#7 Breadcrumb data:** `BreadcrumbList` added to the blog page and to every legal page (built from the visible trail). The terms page's own copy was removed so it isn't duplicated.

Issues #1, #2 and #10 need account access (§9). #8 and #9 are your decisions (§8).

## 7. Security improvements (current state)

- Next.js 16.4.6; 0 production vulnerabilities in both apps.
- Live headers confirmed: `X-Frame-Options: DENY`, `nosniff`, `Referrer-Policy`, the enforced CSP (`frame-ancestors 'none'` and others), a report-only full CSP, and HSTS (from Vercel).

## 8. Outstanding warnings

1. **The live database is down** (issue #1). It is the most important item before relying on the site for leads: queued enquiries live only in server memory and are lost if the backend restarts before the database comes back.
2. **No automated tests.** Add API tests for the contact route (validation, honeypot, queueing) and the admin auth guard, plus a small Playwright smoke test of the scripts used here.
3. **Mobile script cost:** framer-motion is still in the shared bundle (header menu, buttons, parallax). Replacing it with CSS for the header and buttons is the next performance step.
4. **No error monitoring:** consider a free Sentry plan for the frontend and backend, or at least Render log alerts.
5. **Unused PNGs** (4.4 MB) in `public/images/services/`. Delete them, or keep them outside `public/` as source files.
6. **WhatsApp:** add a `https://wa.me/919624498325` link if that number is on WhatsApp.
7. **Lab vs field:** mobile lab LCP is 3.2–4.5 s under Lighthouse's simulated slow-4G profile. Real-user Core Web Vitals will only be known once Google collects field data.
8. **Uncommitted work from other sessions** (the backend 503 → 200 change and an image) should be reviewed by whoever made it before the next deploy.
